# 표지공방

시간표를 아는 표지 메이커. 수업 자료와 과제 파일(PDF·사진·워드)을 넣으면 과목을 찾아 표지를 붙이고, 파일명까지 규칙대로 정리해 주는 대학생용 웹 도구입니다.

**2026 KHU AI Challenge (AI 활용 경진대회) · AI 문제해결 솔루션 부문 출품작**

## 주요 기능

- 시간표 연동: 파일명, 받은 시각, 지금 수업 시간으로 과목 자동 분류. 시간표 캡처를 넣으면 AI가 과목·시간을 읽어 채움
- AI 읽기: 문서 앞 3쪽(스캔본은 이미지)을 읽고 제목·과목·용도(제출용/수업 자료)·요약을 채우며, 판단 근거를 문서 속 문장과 쪽 번호로 표시
- 과제 마감: 과제 안내문에서 마감일·분량·제출 방법을 찾아 D-day 목록으로 관리하고, 제출 파일을 해당 과제에 연결
- 표지 8종: 과제 표지(REPORT), 경희 공식, 클래식, 모던, 바인더 인덱스, 몽글몽글, 다이어리, 나만의 디자인
- 과목별 규칙(파일명·표지 양식·분반), 조별 과제(조원 표), 양면 인쇄용 빈 쪽, 인쇄 묶음·ZIP 내려받기

## 사용 방법

1. 페이지를 열고 "예시 지우고 시작"을 누르면 첫 설정(내 정보 → AI 연결 → 시간표)이 시작됩니다.
2. 키가 없으면 "AI 읽기 체험"으로 데모 문서 3개를 미리 준비한 결과로 체험할 수 있습니다. 실제 AI 읽기는 ChatKHU API Gateway 키(또는 Anthropic API 키)를 넣으면 작동합니다. 키는 사용자의 브라우저에만 저장됩니다.
3. 파일 변환은 모두 사용자 기기 안에서 이뤄지며, AI에는 문서 앞부분만 전송됩니다.
